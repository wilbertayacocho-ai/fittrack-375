FITTRACK 375 — HOME SCREEN WEB APP PACKAGE

Important: iPhone Safari can only install a Home Screen web app from a public HTTPS URL. This folder must first be hosted on a static HTTPS host (for example GitHub Pages or Netlify). Opening index.html directly from Files is not enough to install it as a PWA.

After hosting:
1. Open the published HTTPS URL in Safari on your iPhone.
2. Tap Share (square with arrow pointing up).
3. Choose Add to Home Screen.
4. Keep “Open as Web App” enabled if shown, then tap Add.
5. Launch FitTrack from the new Home Screen icon.

Tracking uses browser local storage on this device/browser. Use Export Backup regularly and save the JSON file in Files. Clearing Safari website data may erase local records.

Apple Health: this web app does not directly connect to HealthKit. That requires a native iOS app and explicit HealthKit permissions.
